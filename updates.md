INTRODUCTION

We are pleased to present this proposal for creative and technical enhancements to support the American
Correctional Association (ACA) in advancing the functionality and user experience of ACA.org. These updates are
designed to build on the existing foundation of the revamped website, further strengthening ACA’s digital
presence and better serving its members and stakeholders.

OVERVIEW

The Objectives
The goal of this enhancement initiative is to improve the digital experience for ACA members by enabling secure
access to exclusive content and introducing new content discovery features. This will be achieved through the
following key objectives:
• Implement Single Sign-On (SSO) for Members

- Integrate SSO functionality to allow ACA members to securely log in using their ACA-provided credentials
- Ensure compatibility with ACA’s existing membership system or identity provider
- Enforce access control to restrict specific content (e.g., Newsletters, Articles) to authenticated members
  only
  • Develop Newsletter Archive with Search and Filter Capabilities
- Design and implement a new Newsletter landing page accessible only to signed-in users
- Create an intuitive UI/UX for browsing, searching, and filtering past newsletters by criteria
- Ensure consistent styling with ACA’s brand and website design
- Enable easy access to full newsletter content via clean, readable layouts
  • Develop Articles Landing Page with Search and Filter Capabilities
- Design and implement a new Articles landing page featuring dynamic filtering and search functionality
- Enhance content discovery through a visually engaging layout that highlights featured or recent articles
- Ensure authenticated access and a consistent experience across content types.
